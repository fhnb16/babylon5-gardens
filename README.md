# Вавилон-5 · Сады — цилиндр О'Нилла

**Версия 2.13.0** · интерактивный пролёт по садам вращающейся космической
станции прямо в браузере.

> **Это не Babylon.js.** «Вавилон-5» — название телесериала (*Babylon 5*), а
> не движка. Проект построен на [three.js](https://threejs.org/).

Внутри цилиндра О'Нилла длиной 3 км и диаметром 1 км: земля свёрнута в кольцо
над головой, по оси горит труба-солнце, от неё к корпусу уходят силовые
опоры, по монорельсу ходит лифт. Можно лететь куда угодно, перелетать между
видовыми точками, прокатиться в кабине монорельса и сделать снимок с
трассировкой пути.

Мир процедурный. Текстуры и геометрия строятся из зерна, звук в браузере синтезирует WebAudio. Веса нейросетевого шумоподавителя OIDN входят в поставку.

## Возможности

### Мир

| | |
|---|---|
| Масштаб | радиус 50, длина 300 юнитов; 1 юнит = 10 м (станция 3 км × 1 км) |
| Корпус | процедурная поверхность, тесселированная по длине; холмы **продавливают сам корпус**, без швов |
| Сектора биомов | три городских, два парковых, поле, два русла реки (`CONFIG.SECT`, в градусах по окружности) |
| Рельеф | пологие холмы (до 140 м радиусом и ~30 м высотой); примерно треть из них — низины с прудами |
| Вода | реки и овальные озёра: глубина в маске, просвечивающее дно на отмели, рябь поперёк русла, пена у кромки, снос ряби по течению |
| Гравитация | центробежная, высотность застройки ограничена долей земной силы тяжести (крыши не выше ~200 м) |
| Зерно генерации | весь мир детерминирован зерном (`mulberry32`); своё зерно, случайное или заводское (1337) — в настройках |

### Город и природа

- **Город** на общей сетке кварталов: улицы и площади нарисованы на текстуре
  корпуса, дома четырёх типов (ступенчатые с террасами, плиты с надстройкой,
  ротонды, розетки) стоят строго в ячейках, 1–6 этажей по 3,5 м.
- **Кровли** со своей развёрткой и материалом, фасады с окнами, ночью окна
  светятся, фонари освещают магистрали.
- **Трафик:** машины на магистралях с белыми фарами и красными габаритами,
  машины на парковках.
- **Деревья:** до ~3800 на пресете ВЫСОКОЕ (×1.3 на УЛЬТРА), плотность зелени
  от 35% до 500%. Три уровня детализации: полная крона с ветром (ближе
  ~340 м), упрощённая (до ~900 м), дальняя — три плоскости под 60°.
- **Кусты-подлесок**, кольца травы у комлей, ветер в кронах.
- **Сезоны:** весна (цветение), лето, осень, зима (снег) — меняют палитру крон
  и кустов. Насыщенность зелени регулируется.
- Деревья не растут в воде, на проезжей части и сквозь конструкции.

### Конструкции

- **Осевая труба-солнце** — светящийся цилиндр вдоль всей оси станции; камера
  в неё не пролетает.
- **Спина станции и монорельс:** два рельса по направлениям, решётчатая
  ходовая балка, кабины-салоны с окнами и сиденьями.
- **Силовые опоры:** четыре узла по три монолитные конические колонны с
  массивными основаниями у корпуса; их тени считаются аналитически.
- **Башня Командования** с остеклённой ротондой («Кабинет коммандора»).
- **Торцы:** ступенчатая воронка из семи кольцевых уступов к ступице с шестью
  спицами, иллюминаторы, ночная подсветка по периметру.

### Свет и смена суток

- Три фазы: **день → золотой закат → лунная ночь**, плавный переход (~3,5 с);
  авто-цикл по кругу (~40 с на фазу).
- Свет — линия на оси: несколько точечных источников вдоль оси (5, на НИЗКОМ — 3)
  плюс полусферный свет; ночью труба тлеет холодным «ночником».
- **Следы домов** — контактные тени, вытянутые вдоль оси (пресеты ВЫСОКОЕ и
  УЛЬТРА); аналитические тени ферм.
- Карты нормалей, построенные из самих текстур; экспоненциальный туман,
  рассчитанный на длину станции.
- По желанию: **свечение огней** (bloom) и **лучи от оси** — по умолчанию
  выключены.

### Навигация

| Режим | Что делает |
|---|---|
| Свободный полёт | WASD / джойстик / стики геймпада, столкновения с геометрией (дерево обхода `three-mesh-bvh`) |
| Два режима горизонта | «горизонт по цилиндру» (верх — к оси станции) или обычный полёт от первого лица с креном |
| Телепорты | 9 видовых точек с плавным перелётом по цилиндрической траектории; во время перелёта камера смотрит по ходу движения |
| Авто-тур | облёт всех точек по кругу с названиями и подписями |
| Поездка на монорельсе | посадка в ближайшую кабину, взгляд остаётся свободным |

Видовые точки: Панорама Садов, Городская площадь, Кабинет коммандора, Осевой
лифт, Силовая ферма, Над солнцем, Торец и спицы, Парковая аллея, Вдоль реки.

Скорость вращения станции настраивается (по умолчанию оборот за 240 с).

### Фото-режим и трассировка

Кнопка с камерой прячет HUD и **останавливает вращение станции**. На панели
съёмки:

| Кнопка | Что делает |
|---|---|
| ✦ Трассировка пути | собственный WebGPU-трассировщик по всей геометрии сцены, накопление до заданного порога шума |
| ✳ Экранные лучи | экранная трассировка: прямой свет от трубы, затенение, переотражённый свет, аналитические отражения трубы и корпуса |
| Пауза и очистка | останавливает накопление и включает шумоподавитель |
| ◉ Показать вклад | отладочный вид: затенение, переотражения, отражения, прямой свет, шероховатость, карта лучей |
| Снимок | PNG, отрендеренный крупнее экрана (×2 по стороне) и ужатый; в имени файла — зерно |

- Счёт идёт **до порога шума** (5 / 3 / 2 / 1%), а не до фиксированного
  числа выборок; на экране — подробная сводка: шум, выборки, время, отскоки,
  разрешение.
- На WebGPU кадр пути проходит через постобработку на том же устройстве. При растровом выводе classic или WebGL2 и доступном WebGPU кадр появляется поверх сцены. Для classic на устройствах без WebGPU сохранён `three-gpu-pathtracer`.
- Для нового трассировщика доступны à-trous и Open Image Denoise (OIDN). Веса OIDN загружаются при первой очистке. Экранные лучи на WebGPU используют AO, SSGI, SSR и очистку по глубине и нормалям.
- В классической растровой цепочке доступны четыре шумоподавителя: À-Trous + G-буфер, кросс-билатеральный,
  glslSmartDeNoise, временное накопление.
- Доля разрешения трассировки: полное, ¾, ½, ⅓.
- На время съёмки все деревья переходят на полную детализацию.
- У трассировки своя экспозиция и яркость трубы — они не влияют на обычный кадр.

### Звук

Всё синтезируется на WebAudio, ни одного сэмпла. Слои зависят от положения
камеры:

| Слой | От чего зависит |
|---|---|
| Гул станции | громче у оси, где механика |
| Ветер | у земли на открытом месте и в быстром полёте |
| Журчание | только вблизи русла |
| Птицы | днём, у земли, в парках и полях |

Звук запускается кнопкой «Начать» (браузеры не дают завести `AudioContext` без
жеста) и замолкает, когда вкладка скрыта.

### Установка как приложение (PWA)

Манифест, иконки 192/512 и maskable, service worker. Worker существует только
для того, чтобы браузер счёл приложение устанавливаемым: **кеша в нём нет**,
каждый запрос идёт в сеть, и приложение всегда свежее. Установка требует
HTTPS или localhost.

### APK для Android и Android TV

Один APK работает на Android 9 и выше. Скачайте `babylon5-gardens.apk` из [релизов проекта](https://github.com/fhnb16/babylon5-gardens/releases) и откройте его на устройстве. Сцена, воркеры и веса OIDN входят в установку. Для полёта интернет не требуется.

На телефоне и планшете доступны обычные панели, касания и мышь. На ТВ автоматически запускается тур. Стрелки пульта переключают виды и фазы, короткое OK управляет туром, долгое OK открывает меню. Чтобы включить системную заставку, откройте в ТВ-меню «Выбрать заставку Android TV» и выберите «Вавилон-5 · Сады» в настройках Android. Кнопка «Назад» закрывает меню, затем завершает заставку.

Релизная версия проверяет стабильные GitHub Releases при запуске и периодически при наличии сети. Для ручной проверки есть пункт «Проверить обновления». Загруженный APK проверяется по SHA-256, идентификатору приложения, номеру версии и сертификату. Установка выполняется из обычного приложения. Android может запросить разрешение на установку из этого источника и показать системное подтверждение.

#### Сборка и подпись

Каждый пуш запускает workflow **Android APK**. Файл доступен в артефакте `babylon5-gardens-apk` в GitHub Actions. Без ключа подписывается отладочный вариант с суффиксом пакета `.debug`. Его можно установить рядом с релизной версией. Для подписанных обновлений настройте в **Settings → Secrets and variables → Actions** четыре секрета репозитория.

| Секрет | Значение |
|---|---|
| `ANDROID_KEYSTORE_BASE64` | Файл Android keystore, закодированный в Base64 |
| `ANDROID_KEYSTORE_PASSWORD` | Пароль хранилища |
| `ANDROID_KEY_ALIAS` | Имя ключа |
| `ANDROID_KEY_PASSWORD` | Пароль ключа |

Храните резервную копию исходного keystore. С настроенными секретами пуш в основную ветку даёт подписанную release-сборку. Чтобы раздать её устройствам, опубликуйте GitHub Release с тегом, соответствующим `VERSION`, например `v2.13.0`. Actions проверит тег, соберёт этот код и прикрепит `babylon5-gardens.apk`. Каждое последующее обновление требует большего номера версии и подписи тем же ключом.

Для локальной сборки установите Android SDK Platform 34 и JDK 21. В корне проекта выполните `npm ci`, `npm run build`, затем в PowerShell `.\android\gradlew.bat -p android :app:assembleDebug`. Результат находится в `android/app/build/outputs/apk/debug/app-debug.apk`.

### Пресеты качества и настройки

| Пресет | Деревьев | Крона, граней | Нормали | Следы домов | Осевых источников | ≈ треугольников |
|---|---|---|---|---|---|---|
| НИЗКОЕ | 1500 | 20 | нет | нет | 3 | 158k |
| ВЫСОКОЕ | 3800 | 80 | 1024 | да | 5 | 549k |
| УЛЬТРА (телефон) | 3800 × 0.85 | 80 | 1024 | да | 3 | 475k |
| УЛЬТРА (ПК) | 3800 × 1.3 | 320 | 2048 | да | 5 | 1190k |

**АВТО** выбирает НИЗКОЕ на телефоне и ВЫСОКОЕ на ПК. Узкое место кадра —
фрагменты, а не вершины, поэтому сильнее всего помогают масштаб рендера,
число осевых источников и дальность прорисовки.

Настройки разложены по вкладкам и **сохраняются** в `localStorage`
(в приватном режиме всё работает, просто без запоминания):

| Вкладка | Что внутри |
|---|---|
| Графика | качество, плотность зелени (35–500%), дальность прорисовки (2,6 / 3,8 / 5,2 км), сглаживание (MSAA ×2/×4/×8 + фильтр FXAA / SMAA / TAA и их сочетания + масштаб рендера ×1…×2), масштабирование FSR 1 (авто / выкл / 77 / 67 / 50%), разрешение трассировки, порог шума, шумоподавитель |
| Эффекты | свечение огней, лучи от оси, трафик, ветер в кронах, авто-цикл освещения |
| Мир | зерно генерации, сезон, насыщенность зелени |
| Движение | режим полёта, чувствительность обзора, скорость вращения |
| Прочее | громкость, счётчик кадров (FPS, худший кадр, вызовы отрисовки) |
| Лучи | отскоков луча, лучей на выборку, марш отражений, отражения в полёте, экспозиция трассировки, яркость трубы |

## Управление

### Клавиатура и мышь

Горячие клавиши привязаны к коду клавиши, поэтому работают и на русской
раскладке.

| Ввод | Действие |
|---|---|
| Клик по сцене | захват мыши (Pointer Lock), обзор мышью; без захвата — обзор перетаскиванием |
| `W` `A` `S` `D` или стрелки | полёт вперёд / влево / назад / вправо |
| `R` / `F` | вверх / вниз |
| `Shift` | ускорение ×3 |
| Колесо мыши, `=` / `−` | базовая скорость 5…40 |
| `Esc` | назад: закрыть шторку, выйти из режима, отпустить мышь |
| `,` / `.` | предыдущая / следующая точка обзора |
| `T` | авто-тур |
| `Y` | поездка на монорельсе |
| `L` / `K` | следующая / предыдущая фаза освещения |
| `C` | авто-цикл освещения |
| `O` | настройки |
| `G` | телепорты |
| `H` | справка |
| `P` | фото-режим |
| `M` | звук |
| `Pause` | пауза |
| Любая клавиша в фото-режиме | прервать экранную трассировку |

### Пульт ТВ и геймпад

Пульт и кнопки геймпада идут через один конвейер: крестовина — те же стрелки.
Все команды сходятся в единый слой действий (`app/input/actions.ts`).

| Пульт | Действие |
|---|---|
| ← / → | предыдущая / следующая точка обзора |
| ↑ / ↓ | следующая / предыдущая фаза освещения |
| OK, короткое нажатие | вкл / выкл авто-тур |
| OK, удержание ≥ 600 мс, или `ContextMenu` | меню настроек |
| Back / `Escape` / `Backspace` | назад |
| Media Play/Pause | пауза |
| Channel +/− | следующая / предыдущая точка обзора |

| Геймпад | Действие |
|---|---|
| A | OK |
| B, Back | назад |
| Start | меню |
| Крестовина | стрелки |
| LB / RB | точка обзора назад / вперёд (Channel −/+) |
| Левый стик | движение |
| Правый стик | обзор |
| Курки | вверх / вниз |

### Режим ТВ

`?mode=tv` (или сохранённая настройка) включает режим экранной заставки для
телевизора: скрыт весь интерфейс и курсор, нет захвата мыши, идут авто-тур и
авто-цикл суток, экран не гаснет (Screen Wake Lock). Меню настроек по долгому
OK целиком управляется крестовиной: фаза, авто-цикл, скорость тура, звук,
сезон, качество, новое зерно; оно закрывается само через 8 с бездействия.
Этот интерфейс используется при запуске APK на телевизоре и в системной заставке Android TV.
Параметр `?mode=web` принудительно выключает режим.

### Сенсорный экран

| Жест | Действие |
|---|---|
| Касание левой половины | джойстик появляется под пальцем — полёт |
| Свайп по правой половине | обзор |
| Кнопки ▲ ▼ у правого края | вверх / вниз |
| Кнопка со спидометром | переключить скорость (медленно / быстро) |
| Касание во время перелёта | отменить перелёт и авто-тур |

### Кнопки интерфейса

Сверху вниз: настройки, полный экран, справка, фото-режим, телепорты (там же
авто-тур и поездка на монорельсе), звук, фаза освещения.

## Быстрый старт

Нужен **Node 24+**.

```bash
npm install
npm run dev        # dev-сервер Vite, откройте адрес из консоли
```

| Команда | Что делает |
|---|---|
| `npm run dev` | dev-сервер Vite с горячей перезагрузкой |
| `npm run build` | статический сайт в `dist/` (`base: './'` — можно класть в любую папку) |
| `npm run preview` | локальный просмотр собранного `dist/` |
| `npm test` | Vitest: тесты ядра, действий, перелёта + legacy-набор + золотые снимки мира |
| `npm run test:legacy` | только исходный самотест (`node test.mjs`) |
| `npm run test:browser` | Playwright на системном Edge: смоук собранного сайта (в том числе ТВ-режим), смоук path tracer |
| `npm run lint` | ESLint |
| `npm run typecheck` | проверка типов TypeScript |

Собранный `dist/` — обычная статика: его можно выложить на любой хостинг.
Для установки как PWA нужен HTTPS. Режим для телевизора:
`<адрес>/?mode=tv`.

## Системные требования

| Что | Требования |
|---|---|
| Сейчас | современный браузер с **WebGL2** и включённым аппаратным ускорением (свежие Chrome, Edge, Firefox, Safari); работает и на телефонах (пресеты НИЗКОЕ и УЛЬТРА-телефон) |
| Трассировка пути | WebGPU для нового PT и OIDN. На устройствах только с WebGL2 доступен прежний PT в режиме classic. |
| Рендерер | По умолчанию classic. В настройках доступны WebGPU с автоматическим откатом на WebGL2 и принудительный WebGL2. |
| Бэкенд ThreeRT | нативный клиент ThreeRT и GPU с аппаратной трассировкой лучей (DX12 ray queries); в обычном браузере ThreeRT рисует растром |

### Целевая структура

Общее ядро используется браузерным растром, трассировщиком пути и нативной игрой ThreeRT.

```text
core/                 движконезависимое ядро: TS, без зависимостей, QuickJS-safe
  config/             данные CONFIG + физическая палитра PHYS
  scene/              контракт SceneDesc (types.ts), buildScene, LOD, динамика
  layout/             раскладка мира (порядок rnd() как сейчас)
  geometry/           порты примитивов three
  raster/             программный растеризатор (подмножество Canvas2D)
  textures/           генераторы текстур поверх raster
  shading/            ядра шейдеров (подмножество TSL) + эмиттеры TSL / WGSL / CPU
  lighting/ camera/ audio/ math/
backends/
  three/              three.js r187: WebGPURenderer + откат WebGL2, TSL-материалы, post
  threert/            нативный бэкенд ThreeRT (свой package.json)
pathtracer/           свой WebGPU path tracer: BVH, WGSL-ядра, интегратор
app/                  UI, точка входа, workers
tools/                снимки мира, запекание, проверки
docs/                 документация
public/               sw.js, манифест, иконки
```

## Архитектура

Ядро описывает мир **данными**, бэкенды превращают данные в картинку.

```text
                    ┌───────────────────────────────────────────┐
                    │ core/  (TS, без three/DOM, QuickJS-safe)  │
 seed, quality,     │  config → layout → buildScene()           │
 season ──────────▶ │  raster → textures                        │
                    │  shading kernels (подмножество TSL)       │
                    └──────────────┬────────────────────────────┘
                                   │ SceneDesc: геометрия, экземпляры,
                                   │ материалы, излучатели, роли
          ┌────────────────────────┼─────────────────────────┐
          ▼                        ▼                         ▼
 backends/three/            pathtracer/               backends/threert/
 WebGPURenderer             WebGPU compute (WGSL):    нативные клиенты:
 + откат WebGL2             BVH, труба-источник       аппаратный RT,
 TSL-материалы, post        с MIS, вода-диэлектрик    раскладка запечена в Node
          │                        │
          └──── общий GPUDevice ───┘
                       │
                     app/  UI, ввод, звук, фото-режим
```

Ключевые решения:

- **Один источник шейдеров.** Ядра пишутся один раз и выводятся в TSL (растр),
  в чистые WGSL-функции `b5_*` (наш path tracer и ThreeRT) и в CPU-код (тесты).
- **Детерминизм.** Один и тот же `seed` даёт тот же мир; порядок вызовов
  генератора случайных чисел сохраняется и сверяется золотыми снимками.
- **Свой path tracer** вместо обходов `three-gpu-pathtracer`: двухуровневый
  BVH, аналитическая труба-источник с MIS, выборка излучающих треугольников,
  вода как диэлектрик; сначала прогрессивный фоторежим, затем реальное время.
- **ThreeRT** выполняет сценарии на TypeScript под QuickJS, поэтому ядро
  обязано обходиться без DOM, Canvas2D и WebAudio.

Подробности и обоснования — в [docs/ROADMAP.md](docs/ROADMAP.md).

## Тестирование

| Уровень | Как запустить | Что проверяет |
|---|---|---|
| Legacy-самотест | `npm run test:legacy` (входит в `npm test`) | то, что ломается молча: порядок инъекций в шейдер корпуса, углы теней ферм, бюджет отрисовки, зеркало UV, видовые точки, перелёты, звук, раскладку настроек, версию |
| Vitest | `npm test` | новые модульные тесты, legacy-набор через обёртку, снимки мира |
| Золотые снимки мира | `node tools/snapshot-world.mjs --check` | что генерация мира не изменилась: матрицы, цвета, хеш корпуса, холмы по сочетаниям зерна и качества |
| Ядро, действия, перелёт, PT | `npm test` | чистота ядра, parity примитивов с three, растеризатор, текстуры, ядра шейдеров, раскладка; слой действий и ТВ-режим (`test/actions.test.ts`), направление взгляда при перелёте (`test/flight.test.ts`); BVH и WGSL-обход против CPU-эталона |
| Браузер | `npm run test:browser` | Playwright на системном Edge: смоук собранного сайта (в том числе сценарий ТВ-режима), смоук path tracer (`tests/browser/`) |
| Статический анализ | `npm run lint`, `npm run typecheck` | ESLint, типы TypeScript |
| План | — | смоук бэкенда three на WebGPU и WebGL2, проверки ThreeRT под QuickJS |

**Снимки обновляются только намеренно:** `node tools/snapshot-world.mjs --write`
— и только когда изменение мира задумано, с объяснением в описании изменений.

## Версии

Текущая версия — **2.13.0**. Формат `мажор.минор.правка`:

- **мажор** — смена основы: другой способ считать картинку, новая внешняя
  зависимость, несовместимая перестройка;
- **минор** — новая возможность;
- **правка** — исправление и доводка.

Номер живёт в одном месте — `js/version.js` (там же массив истории); оттуда
его читают интерфейс и сервис-воркер, а тест проверяет, что README называет
